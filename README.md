# Kairui Feng's CV

This repository contains the English and Chinese source files for Kairui Feng's PhD application CV.

| File | Description |
| --- | --- |
| `Feng_Kairui_PhD_CV.tex` | English CV |
| `Feng_Kairui_PhD_CV_CN.tex` | Chinese CV |
| `resume.cls` | Self-contained resume template class |

PDFs are built automatically by GitHub Actions after each push. Open the latest successful run under the **Actions** tab and download the `cv-pdfs` artifact.
